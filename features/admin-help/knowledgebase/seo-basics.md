# SEO Basics for Estate Brothers Admin

## Core principle

SEO content should help real people first. Search engines should see the same useful content that users see.

## Titles

Use clear titles. Do not repeat the brand twice.

Good:

- `About | Estate Brothers`
- `DHA Lahore Plots for Sale | Estate Brothers`

Bad:

- `About | Estate Brothers | Estate Brothers`
- `Best Best Best Property Deals`

## Meta descriptions

A meta description should summarize the page in one or two clear sentences. It should be specific enough to help users decide whether to click.

Good descriptions mention the page topic, location, service, or proof.

Avoid:

- keyword stuffing
- fake urgency
- vague claims
- repeated phone numbers

## Headings

Use headings to explain the page structure. A heading should make sense to a human scanning the page.

## Images and alt text

Every important image should have useful alt text.

Good:

- `Company registration certificate for Estate Brothers`
- `Tajamal Hussain at the Estate Brothers office`

Bad:

- `image`
- `photo`
- `best real estate`

## Structured data

Structured data should describe visible page content only. Do not add hidden claims just for SEO.

Awards and certificates can support Organization schema. Video schema should only be added when there is a real video URL and thumbnail.

## Indexing

Use published/indexable only for complete public content. Use draft, review, or noindex when content is incomplete.

## What Google-style quality expects

- original, useful information
- clear ownership and trust signals
- accurate business details
- no misleading claims
- no thin pages made only for keywords

# Listings Admin Guide

## Purpose

Listings are public property records. They need accurate facts, clear media, and SEO-safe descriptions.

## Important fields

- Title: clear property name.
- Slug: URL-friendly identifier.
- Listing type: plot or house.
- Location/phase/city: must match the real property.
- Size/price/status: must be accurate.
- Availability: sold/available/under offer should not be confused with publication status.
- Description: should be factual and useful.
- Media: should show the real property or relevant approved visuals.
- Meta title and description: should summarize the listing for search.

## SEO rules

- Do not publish thin listings with missing facts.
- Avoid generic filler like `hot deal` or `golden opportunity`.
- Use specific location and property details.
- Keep sold status accurate.
- Use descriptive image alt text.
